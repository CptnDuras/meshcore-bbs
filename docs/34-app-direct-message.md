# Spec 34 — App: Direct message thread

## Dependencies
Spec 33 (People tab).

## Design language
- Same bubble style as Room (consistency)
- App bar: back arrow, person's name
- Pending/confirmed/failed same as Room
- Feel: 1:1 chat, familiar like any messaging app

## Task
Tap person → open DM thread, send/receive.

## Deliverables
- Thread view with message bubbles
- Compose + send DM
- Receive DMs inline

## Acceptance criteria
- [ ] Tap person opens thread
- [ ] Send DM works
- [ ] Incoming DMs appear
- [ ] Feels like texting, not "mail"

## Test
Manual: tap person, send DM, receive reply.
