# meshbbs guided help: the default text, compiled in as a data file.
#
# Where help comes from (first that exists wins):
#   1. the database  (HELPIMPORT copies a file into it)
#   2. ./help.txt next to the daemon, to override this default without a rebuild
#   3. this file
# After editing 2 or 3 send HELPRELOAD (sysop) or restart the daemon.
#
# Sections (a line "[kind ...]" starts one):
#   [message name]       a text. {bbs} {who} {query} are filled in.
#   [topic N key]        one menu screen. N is the digit users reply with (1-9).
#                        headers: title, aliases, perm, try, note (repeatable)
#   [command NAME]       the help entry for one command, written next to its
#                        screen. NAME is the command's primary name in the code.
#                        headers: names (all names, as registered), topic,
#                        usage, summary, example, perm
#
# A topic screen is built from its commands: "usage = summary" per line, then
# notes, then "Try:". Keep a screen under 150 bytes so it fits one radio message.
# perm is who sees it: unverified, user, aide or sysop. HELP ALL and HELP <command>
# are generated from the command entries. A test fails if a registered command
# has no entry here, or an entry names a command that does not exist.

[message menu_header]
HELP - reply with a number:

[message menu_footer]
HELP ALL = every command

[message no_topic]
No help for "{query}".

[message welcome]
Welcome to {bbs}! You are {who} (an account was made for you, no signup). Start here: 1) R reads the general room 2) K lists rooms, C <room> switches 3) E <subject> posts. Send HELP any time for a guided menu.
